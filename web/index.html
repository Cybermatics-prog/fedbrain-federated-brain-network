EXECUTION RECIPE

Data processing and evaluation

Implementation summary
  1. 01

    Data and site selection

    ABIDE I preprocessed data: KKI, NYU, UCLA_1, UM_1, USM, and YALE. Published per-site counts are references; actual cohorts follow local data and the run manifest.

  2. 02

    Consistent preprocessing

    CPAC / filt_noglobal / AAL116; 0.01–0.1 Hz band-pass filtering without global signal regression. Connectivity matrices contain 116 ROIs.

  3. 03

    Windows and connectivity features

    32-frame windows with stride 1; Pearson correlations and Fisher z transformation; 6,670 upper-triangle connectivity features.

  4. 04

    Federated training and personalized fusion

    L₁ sparse selection, MMD alignment, and gated global/private experts; 50 rounds by default. Select FedAvg for the federated averaging baseline.

  5. 05

    Subject-level splitting and evaluation

    Split subjects before generating windows; no subject crosses train, validation, or test sets. Fit learned selection and scaling on training data only; report test results separately.

IMPLEMENTATION TRANSPARENCY

Implementation notes

A hyperparameter inconsistency in published descriptions

Published descriptions disagree: the method description uses λM = 0.01, while a later summary uses 0.1. The local default is 0.01; saved run configurations are authoritative.
